# 💇‍♀️ حسابداری سالن آرایش زنانه

نرم افزار حسابداری ساده و زیبا برای مدیریت سالن آرایش زنانه

## ✨ امکانات

- **💰 ثبت تراکنش**: ثبت سریع خدمات مشتری با تفکیک کارمند
- **👥 مدیریت کارمندان**: اضافه/ویرایش/حذف کارمندان با تخصص
- **🛎️ مدیریت خدمات**: لیست خدمات با قیمت پیش‌فرض
- **📊 گزارش روزانه**: مشاهده تراکنش‌های امروز با خلاصه آمار
- **📅 گزارش ماهانه**: درآمد هر کارمند به تفکیک دسته خدمت
- **📥 خروجی اکسل**: صدور گزارش ماهانه به فایل اکسل
- **储 ذخیره در اکسل**: تمام داده‌ها در فایل‌های اکسل ذخیره می‌شوند

## 🚀 نحوه اجرا

### پیش‌نیازها
- Python 3.8+
- پکیج openpyxl
- tkinter (معمولاً با پایتون نصب است)

### نصب وابستگی‌ها
```bash
pip install openpyxl
```

### اجرای برنامه
```bash
python salon_app.py
```

## 🎯 راهنمای استفاده

### ۱. ثبت تراکنش (صفحه اصلی)
1. نام مشتری را وارد کنید
2. خدمت مورد نظر را انتخاب کنید
3. کارمند انجام‌دهنده را انتخاب کنید
4. مبلغ را تأیید یا تغییر دهید
5. روی «افزودن» کلیک کنید
6. خدمات بیشتر اضافه کنید
7. روی «ثبت نهایی» کلیک کنید

### ۲. مدیریت کارمندان
- تب «کارمندان» → افزودن/ویرایش/حذف
- هر کارمند تخصص دارد (مو، ناخن، ابرو، مژه)

### ۳. گزارش‌ها
- **گزارش امروز**: جمع کل، تعداد مشتری، لیست تراکنش‌ها
- **گزارش ماهانه**: درآمد هر کارمند به تفکیک دسته

## 💡 نکات

- قیمت خدمات به صورت خودکار از لیست خدمات پر می‌شود
- امکان تغییر مبلغ برای هر تراکنش وجود دارد
- شماره تلفن مشتری اختیاری است
- داده‌ها به صورت خودکار در فایل‌های اکسل ذخیره می‌شوند
- امکان خروجی گزارش ماهانه به فایل اکسل جداگانه
